# AresPath frontend

Independent Vite/Three.js application. Run `npm ci` and `npm run dev`.
The globe is `/`; the working terrain API explorer is `/tiles.html`.
`npm test` checks the client contract; `npm run build` produces `dist/`.

See [the framework guide](../docs/FRAMEWORK.md) for backend setup, scientific
data preparation, API coordinates, deployment behavior and remaining work.
